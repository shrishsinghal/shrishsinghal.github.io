01 — Focus

What I work on

My quantitative work is systematic strategy research. At NYU I built long/short strategies on NASDAQ, the S&P 500 and the Dow using LSTM and SARIMA models over ten years of index data, with macroeconomic series such as the 10-year Treasury added as regime context. That included the infrastructure underneath — ingestion, feature engineering, a backtester, and P&L and risk reporting — and position sizing against realized volatility.

At Boson Motors I work on high-frequency sensor telemetry: anomaly detection that flags component failures up to two weeks out, reinforcement learning for vehicle control, and LLM agents wired into live vehicle APIs. The day-to-day problems overlap more than the domains suggest — noisy time series, models that drift, and monitoring built to catch it.

GitHub ↗

Supervised fine-tuning of Llama 3 8B with LoRA and 4-bit quantization, reaching 82.5% on a mathematical reasoning benchmark. Gradient checkpointing and Unsloth cut training time about 20% on a single consumer GPU.

Subzero Signals — IceCube neutrino analysis

GitHub ↗

100GB of detector data through Spark Streaming for batch and real-time processing, then a 3× speedup by moving the hot path to Polars. A CNN beat the linear baseline on event direction (azimuth RMSE 1.83 → 1.5), with KNN and similarity search served from a vector database.

Personalized image generation with SDXL

GitHub ↗

Stable Diffusion XL fine-tuned with DreamBooth and LoRA to learn a subject from five photographs. Gradient checkpointing and mixed precision dropped memory overhead 30%; a Flask and Gradio front-end made it usable in real time.

TwitterTracker — behavioral signals from tweet history

GitHub ↗

A BERT model trained on scraped tweets to estimate loneliness, anxiety and stress levels for an account, surfaced through a Streamlit dashboard.
